Project Overview

Root folder: Arcarna-Engine/

Core engine modules: ECS, Math, Physics, Scene, Scheduler, EntryPoint.

User workspace: Source/Workspace/ contains the startup script and asset placeholder structure.

Tests: Test/ contains unit test drivers for ECS, Physics, Scene, Vector2, and Angle.

Build & Run

make compile        # Build app executable
make run            # Run app
make compile-test-ecs
make compile-test-scene
make compile-test-vector2
make compile-test-angle
make compile-test-physics
make run-test        # Run test executable

Architecture Summary

  • ECS: Entities, bitmask-based component lookup, component pools.
  • Physics: RigidBody and Transform, gravity simulation, frame integration.
  • Scene: Scene wrapper around its own world instance.
  • Scheduler: Frame update entrypoint for the engine loop.
  • EntryPoint: Fixed 60 FPS main loop in App.cpp.
